# pelican-acore-cms

Unofficial community integration for deploying and managing [ACore-CMS](https://www.azerothcore.org/acore-cms/) with [Pelican](https://pelican.dev/).

## Status

Early development.

## Goals

- Run ACore-CMS as a Pelican-managed server
- Package the required web stack into a single container
- Preserve CMS data and configuration across updates
- Support external MySQL
- Support AzerothCore database and SOAP integration
- Provide versioned, stable, and development container images
